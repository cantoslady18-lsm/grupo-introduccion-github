# grupo-introduccion-github
Práctica de control de versiones con Git y GitHub.
Este repositorio fue creado para el Examen Práctico 2 de la asignatura Introducción a la Ingeniería de Software.
Su propósito es practicar el control de versiones con Git y GitHub: registrar cambios en un archivo con commits descriptivos y trabajar de forma colaborativa entre los integrantes del equipo.
